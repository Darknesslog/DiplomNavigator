# Матрица эндпоинтов и трассировки backend

Дата актуализации: 18.11.2026. Проверенный backend: `95ca12e`.

Границы веток, предложения приоритетов и вопросы для согласования:
[пакет ревью](backend-review-appts.md). Диаграммы:
[архитектура](architecture.md), [процесс и состояния](workflow.md).

Документ описывает backend без frontend и загрузки файлов. Статус
«демонстрация» означает историческую отметку показа через Swagger. Новый ручной
показ в рамках сверки 18.11 не выполнялся. Статус
«вне демонстрации» означает, что функция реализована и покрыта backend-тестами
или проверялась отдельно. «Технический долг» означает отсутствие функции либо
неполное покрытие заявленного user flow.

## 4. Итог

- Реализованные backend-маршруты: покрывают авторизацию, роли, темы, заявки,
  закрепления, прогресс, уведомления, ручные назначения и архивирование.
- Основной backend user flow поддерживает создание/публикацию, заявку, решение,
  закрепление, прогресс, защиту и архив. Существующие правила не покрывают весь
  заявленный объём MVP и требуют решений по спорным переходам.
- Основные функции, не вошедшие в запись, доступны для отдельного показа через
  Swagger и покрыты автоматическими тестами.
- Проверка 18.11.2026: **125 SQLite + 97 PostgreSQL**. Полный
  [протокол и ограничения](test-summary.md). Google-реестры не обновлялись:
  в API-листе пока нет двух операций истории/отзыва допуска, в трассировке —
  дополнений текущего плана. Подробнее в [пакете ревью](backend-review-appts.md).
